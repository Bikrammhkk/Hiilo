# **App Name**: PaperCat

## Core Features:

- Paper Search: Allows users to search for papers by keywords, subjects, and semesters.
- Dynamic Filtering: Allows the filtering of question papers according to subject and semester
- External Link Conversion: The app will identify links to external services such as Google Drive, and convert them into direct download links, using a tool. This is useful because direct downloads are not always straightforward from Drive. This will save users the trouble of multiple redirects or navigation
- Easy 'Contact Us': Allows users to quickly connect with the maintainers, and/or connect to external sites with more material (instagram etc.)

## Style Guidelines:

- Primary color: Slate blue (#708090) for a calm, intellectual feel.
- Background color: Light gray (#F5F5F5), close in hue to the primary color, provides a neutral backdrop.
- Accent color: Soft gold (#BDB76B), a more saturated analogous color, highlights interactive elements.
- Body and headline font: 'PT Sans' (sans-serif) provides a modern yet readable feel.
- Use simple, clear icons to represent file types and actions, maintaining a clean aesthetic.
- Maintain a clean, card-based layout for easy navigation and content display.
- Subtle animations on button hover and content loading to improve user experience.
